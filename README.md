# 🎬 StreamVault

Lecteur de réactions d'anime avec synchronisation cloud.

👉 **[Accéder au site](https://anous546832.github.io/)**

---

## 🚀 Fonctionnalités

- **Navigation** : Créateurs → Séries → Vidéos
- **Chapitres** : Navigation par timecode dans les longues vidéos
- **Sagas & Arcs** : Organisation visuelle pour les longs animes (One Piece, Naruto)
- **Watch Together** : Regarder à plusieurs avec synchronisation pause/play/timecode
- **Cloud Sync** : Progression sauvegardée et synchronisée entre appareils (Supabase)
- **Mode développeur** : Création de chapitres, export data.json, import/export progression
- **Mode cinéma** : Interface minimaliste pour une immersion totale
- **Responsive** : Adapté mobile (portrait et paysage)

---

## 🛠 Stack

- HTML / CSS / JavaScript vanilla
- [Supabase](https://supabase.com) (cloud sync + watch together)
- [Player.js](https://playerjs.com) (lecture Streamable)
- GitHub Pages (hébergement)
